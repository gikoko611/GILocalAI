GI CODE & VIDEO STUDIO
WebView executes HTML, CSS, JavaScript, SVG, and JSON tools locally. Other languages are source-editor modes until a compatible runtime/compiler is bundled.

AI VIDEO CREATOR

Describe a scene. Online AI writes Canvas animation code; render it locally to MP4. For offline use, enter code manually below.

AI generation uses your configured Online API provider and model from Settings. API video-generation endpoints are not assumed; this creates animation code, then renders it on-device.

Canvas frames are rendered at fixed timestamps and streamed into Android MediaCodec H.264. An optional soundtrack is muxed into the MP4.

TIMELINE EDITOR

Timeline uses seconds. Select a segment to export only that range.

SUBTITLE BURN-IN

AUDIO TRACK

No soundtrack selected. Choose an audio file (MP3, M4A, AAC, WAV or another Android-supported format) to mux into the exported MP4.

The selected audio track is copied into the MP4 without decoding, keeping memory use low. This first audio pass supports one soundtrack track; per-track volume, multiple-track mixdown and fades are planned as the next audio-engine layer.

Code runs once per frame with t in milliseconds. Use ctx (CanvasRenderingContext2D), width and height. Do not use requestAnimationFrame; timestamps are supplied by the renderer.

Rendered video will appear here after export.
Use 480p and 24 FPS first on Redmi 9A. Keep the app open during rendering.
